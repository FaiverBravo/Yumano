## Personalidad de Marca y Estilo
Este sistema de diseño rinde homenaje al equilibrio entre el entorno natural y el legado cultural. La personalidad de la marca es **profesional, orgánica y serena**, evocando una sensación de atemporalidad y respeto por la artesanía. El objetivo es transmitir tranquilidad y confianza a través de una estética limpia que permite que el contenido histórico y ambiental sea el protagonista.

El estilo visual se define como una mezcla de **Minimalismo Moderno** con toques **Táctiles**. Se aleja de la frialdad tecnológica para abrazar texturas sutiles, una paleta cromática terrosa y una legibilidad impecable. El resultado debe sentirse como un archivo moderno o un centro de interpretación de alta gama: estructurado pero profundamente conectado con la tierra.

## Colores
La paleta está inspirada en los pigmentos naturales y el paisaje forestal.

- **Verde Bosque Profundo (Primario):** Utilizado para la estructura principal, navegación y elementos de autoridad. Aporta estabilidad y una conexión directa con la naturaleza.
- **Terracota/Tierra (Secundario):** Un color de acento cálido para llamadas a la acción (CTAs) y elementos que requieren atención, evocando la cerámica y el suelo.
- **Arcilla Sutil (Terciario):** Utilizado para elementos de apoyo, estados secundarios y detalles decorativos.
- **Arena Cálida (Neutral):** El lienzo del sistema. Sustituye al blanco puro para reducir la fatiga visual y aportar una calidez orgánica a las superficies.

El contraste debe ser siempre elevado, asegurando que el texto oscuro sobre los fondos arena cumpla con los estándares de accesibilidad AA/AAA.

## Tipografía
Se utiliza exclusivamente **Hanken Grotesk** para proyectar una imagen moderna pero con una geometría suave que se siente orgánica. 

Las jerarquías se establecen mediante variaciones drásticas de peso y tamaño. Los titulares grandes deben tener un interlineado ajustado y un espaciado entre letras ligeramente negativo para una apariencia editorial. Para el cuerpo de texto, se prioriza la legibilidad con un interlineado generoso (1.6), permitiendo que el contenido "respire" sobre el fondo color arena. Las etiquetas (labels) utilizan un espaciado entre letras expandido y un peso medio para diferenciarse claramente de los bloques narrativos.

## Diseño y Espaciado
Este sistema de diseño emplea una **rejilla fluida** basada en un sistema de 12 columnas para escritorio y 4 columnas para dispositivos móviles.

La filosofía de espaciado es generosa, utilizando el "aire" como una herramienta de diseño para enfatizar la tranquilidad del patrimonio cultural. Se debe evitar la densidad excesiva de información. 
- **Escritorio:** Márgenes amplios (64px) para centrar la atención en el contenido narrativo.
- **Móvil:** Márgenes de 16px con un colapso de elementos verticales para mantener la jerarquía.
- **Ritmo Vertical:** El espaciado entre secciones debe ser consistente (80px o 48px) para crear una cadencia de lectura predecible y pausada.

## Elevación y Profundidad
La jerarquía visual se comunica mediante una combinación de **capas tonales y sombras ambientales muy suaves**. 

En lugar de sombras negras genéricas, se utilizan sombras con un ligero matiz del color primario (verde bosque) o terracota, con una opacidad muy baja (10-15%) y una difusión (blur) alta. Esto crea una sensación de objetos que descansan físicamente sobre una superficie, como papel sobre madera o piedra.

Las superficies secundarias utilizan cambios sutiles de color (de Arena a una Arcilla muy clara) para definir contenedores sin necesidad de líneas divisorias agresivas, manteniendo la estética limpia y abierta.

## Formas
El lenguaje de formas es **suave y acogedor**. Se implementa un radio de esquina estándar de **8px** (Nivel 2) para la mayoría de los componentes, como botones y tarjetas. 

Este redondeo suaviza la rigidez del diseño profesional, alineándose con las formas que se encuentran en la naturaleza y la artesanía manual. Los elementos de interacción más pequeños (como checkboxes) mantienen este redondeo proporcionalmente, mientras que los elementos de gran escala (como secciones de fondo) pueden permanecer rectos para denotar estabilidad estructural.

## Componentes

- **Botones:** El botón primario es de color Verde Bosque con texto en Arena Cálida. El botón secundario utiliza un borde fino en Terracota con texto del mismo color. El radio de esquina es estrictamente de 8px.
- **Tarjetas (Cards):** Fondo ligeramente más claro que el neutral principal o blanco roto, con una sombra ambiental mínima y bordes redondeados. Se utilizan para destacar hitos culturales o artículos de blog.
- **Campos de Entrada (Inputs):** Bordes sutiles en color Arcilla que se vuelven Verde Bosque al recibir el foco. El fondo debe ser ligeramente más oscuro que el fondo de la página para crear profundidad.
- **Chips:** Utilizados para categorías taxonómicas (ej. "Arqueología", "Botánica"). Tienen un fondo sólido en Arcilla con texto en Verde Bosque, con bordes totalmente redondeados (pill-shaped).
- **Listas:** Espaciado amplio entre elementos con divisores de un solo píxel en un color Arcilla muy tenue (opacidad 20%).
- **Iconografía:** Líneas finas y orgánicas, preferiblemente en Verde Bosque, evitando estilos rellenos o excesivamente pesados para mantener la ligereza visual.
